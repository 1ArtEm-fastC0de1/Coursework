# 3D платформенна гра "Jump Dash"
# Постановка завдання
  Jump Dash - 3D платформенна гра, призначена для курсової роботи на рушії Godot. 
  У грі є 5 рівнів і на кожному з них є певний рівень складності перешкоди, які головний герой повинен пройти за хвилину, зібравши при цьому усі монети, не впавши вниз, не бути вбитим ворогом та не потрапити на шипи. 
  У грі є тільки одна спроба, тобто якщо головний герой програє, то все почнеться спочатку.
# Функціональні вимоги
  * гра повинна давати можливість гравцю керувати персонажем у тривимірному просторі за допомогою клавіатури та обертання камерою навколо персонажа;
  * гра має містити колізії на платформах, можливість стояти на них;
  * гра повинна перевіряти, чи гравець програв, зістрибнувши вниз і чи не наступив персонаж на ворога або на іншу перешкоду;
  * гра повинна містити лічильник монет та таймер, до закінчення якого персонаж повинен зібрати всі монети;
  * гравець повинен мати можливість збирати монети;
  * гра повинна перевіряти, чи зібрав персонаж усі монети, і якщо зібрав, то гравець переходить на інший рівень.
# Нефункціональні вимоги
  * інтерфейс гри повинен бути мінімалістичним та чітким;
  * гра повинна бути добре оптимізована для ПК та мати мінімальні вимоги до ресурсів для її коректної роботи;
  * рух головного персонажа та камери не повинні мати затримок.

Під час розробки гри було використано рушій Godot та вбудована у Godot мова програмування GDScript.
Використано такі бібліотеки, як Godot.CharacterBody3D, Godot.Area3D, Godot.Node, Godot.Node3D, Godot.Control. Також всі моделі розроблені у Blender.

# Для запуску гри:
* скачайте архів;
* розпакуйте у зручне для вас місце;
* перейдіть у папку "3d-platformer";
* відкрийте файл "Jump Dash.exe".
